## O projekcie

Drobne narzędzia wielokrotnego użytku. Na razie `pagination.py`: `paginate(items, page, limit)` zwraca jedną
stronę wyników razem z liczbą wszystkich pozycji i stron. Repozytorium GitHub `MKadvanceddesign/utils` jest
**publiczne**.
